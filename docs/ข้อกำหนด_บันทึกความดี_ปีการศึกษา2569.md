## ๑. ระยะเวลาและเกณฑ์
- ปีการศึกษา ๒๕๖๙: **๑ กรกฎาคม ๒๕๖๙ – ๓๐ มิถุนายน ๒๕๗๐**
  - ภาคการศึกษาที่ ๑: ๑ ก.ค. – ๓๐ พ.ย. ๒๕๖๙
  - ภาคการศึกษาที่ ๒: ๑ ธ.ค. ๒๕๖๙ – ๓๐ มิ.ย. ๒๕๗๐
- นพอ. ทุกนายต้องมีชั่วโมงความดีจิตอาสาที่ได้รับอนุมัติ **อย่างน้อย ๕๐ ชั่วโมงต่อปีการศึกษา** (เฉลี่ยภาคละ ๒๕ ชั่วโมง)
- นับเฉพาะรายการที่อาจารย์ผู้ตรวจ **อนุมัติแล้ว** เท่านั้น

## ๓. วิธีบันทึก (เปลี่ยนจากแบบฟอร์มเดิมเป็นระบบบันทึกความดี)
1. เปิด LINE Official Account ของวิทยาลัย แล้วกดเมนู "บันทึกความดี" (หรือเปิดเว็บ rtafnc-gooddeeds.pages.dev)
2. ระบบเข้าสู่ระบบอัตโนมัติด้วย LINE ที่ผูกกับรหัส นพอ. แล้ว · ครั้งแรกให้เข้าด้วยรหัส นพอ. ๗ หลัก และเปลี่ยนรหัสผ่านทันที
3. เมนู "✍️ บันทึกความดี" → เลือกหมวด → กรอกวันที่ ชั่วโมง รายละเอียด → แนบรูป → ส่ง (ระบบแสดงโควตาคงเหลือและเตือนเมื่อเกินเพดาน)
4. ส่งลิงก์ขอรับรองให้ผู้รับรอง (อาจารย์ / ผู้ปกครอง / หน่วยงานภายนอก / อื่น ๆ) ลงลายมือชื่อบนหน้าจอ
5. รออาจารย์ตรวจ (มาตรฐาน ๗ วันทำการ)

## ๔. การแจ้งผล (แทนอีเมลตอบกลับของแบบฟอร์มเดิม)
ระบบแจ้งทาง **LINE** (เมื่อผูก LINE แล้ว) และ **อีเมล** (เมื่อกรอกอีเมลในหน้าโปรไฟล์) เมื่อ
- ส่งรายการความดี/ผลวิ่งสำเร็จ (ได้รับแล้ว รอตรวจ)
- อาจารย์อนุมัติ หรือไม่อนุมัติ (พร้อมเหตุผล)
- ข้อมูลส่วนตัวถูกแก้ไข (ถ้าไม่ได้แก้เอง ให้แจ้งอาจารย์ทันที)
- ชั่วโมงสะสมครบ ๕๐ ชม.

## ๕. การตรวจสอบชั่วโมง
- หน้า "หน้าหลัก" แสดงชั่วโมงสะสมปีการศึกษา ๒๕๖๙ เทียบเกณฑ์ ๕๐ ชม. แยกรายหมวด
- หน้า "ประวัติความดี" แสดงทุกรายการพร้อมสถานะ (รอตรวจ / อนุมัติ / ไม่อนุมัติ) และพิมพ์ใบบันทึกความดี A4 ได้
- ข้อสงสัยติดต่อแอดมินชั้นปี หรือพิมพ์ข้อความใน LINE Official Account
