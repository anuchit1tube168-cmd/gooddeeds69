## 📱 2. คู่มือสำหรับนักเรียน (Student User Manual)

### ขั้นตอนที่ 1: การเข้าสู่ระบบ
1. กดเปิดลิงก์ `https://liff.line.me/2010948179-Ympqt2bT` ในแชต LINE หรือกดปุ่มเมนูใน **LINE Official Account (LINE OA)**
2. ระบบจะทำการ **Auto-Login** หากผูกบัญชีไว้แล้ว หรือกรอก **รหัสนักเรียน** (รหัสผ่านเริ่มต้นคือ รหัสนักเรียน)
3. เมื่อเข้าสู่ระบบ จะพบกับหน้า **Student Dashboard** แสดงยศระดับความดี (Level 1-8) และจำนวนชั่วโมงสะสม

### ขั้นตอนที่ 2: การบันทึกความดีใหม่
1. กดปุ่ม **"บันทึกความดีใหม่"**
2. เลือก **หมวดหมู่กิจกรรมจิตอาสา** (มีให้เลือก 9 หมวดหมู่)
3. พิมพ์ **ชื่อกิจกรรม / คำอธิบาย** และ **จำนวนชั่วโมง**
4. กดแนบ **รูปถ่ายกิจกรรม** (ระบบจะบีบอัดรูปให้อัตโนมัติเพื่อความรวดเร็ว)
5. กดปุ่ม **"ส่งบันทึกความดี"** ➡️ รูปถ่ายจะถูกส่งไปเก็บในโฟลเดอร์ Google Drive รายบุคคลทันที!

### ขั้นตอนที่ 3: การแชร์การ์ดความดีเข้า LINE
- พอบันทึกสำเร็จ สามารถกดปุ่ม **"แชร์การ์ดความดี"** เพื่อส่งการ์ดสรุปความดีสวยๆ เข้าไปในแชต LINE เพื่อนหรือกลุ่มไลน์รุ่นได้ทันที

## 👩‍🏫 3. คู่มือสำหรับอาจารย์ / ผู้ดูแลระบบ (Teacher & Admin Manual)

### ขั้นตอนที่ 1: การเข้าสู่แผงควบคุม (Dashboard)
1. เปิดเข้าเว็บ: [https://anuchit1tube168-cmd.github.io/gooddeeds69/frontend/teacher-dashboard.html](https://anuchit1tube168-cmd.github.io/gooddeeds69/frontend/teacher-dashboard.html)
2. ล็อกอินด้วยบัญชีอาจารย์/แอดมิน:
   - **อาจารย์ (Teacher):** Username `teacher` | Password `teacher` (หรือ `teacher69`)
   - **ผู้ดูแลระบบ (Admin):** Username `admin` | Password `admin69`

### ขั้นตอนที่ 2: การตรวจรับรองและอนุมัติความดี
1. ในหน้า **Teacher Dashboard** จะแสดงรายการความดีที่นักเรียนยื่นเข้ามาแบบ Real-time
2. คลิกดูรายละเอียด รูปถ่ายกิจกรรม และจำนวนชั่วโมง
