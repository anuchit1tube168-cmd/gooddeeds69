ฉบับที่วันที่สาระสำคัญ
๑.๐ก.ค. ๒๕๖๙ประกาศใช้ครั้งแรก — การบันทึกความดี ๙ หมวด ลายมือชื่อดิจิทัล การเลื่อนชั้นปี
๒.๐๑๑ พ.ย. ๒๕๖๙เพิ่มหมวด ๑๐ วิ่งเพื่อสุขภาพ, การทดสอบสมรรถภาพ, ค่าพลังรายคน, ฐานข้อมูลรายบุคคล, การคุ้มครองข้อมูลส่วนบุคคล และการดูแลระบบ; ปรับโครงสร้างเอกสารและตัวชี้วัด
๒.๑๑๑ พ.ย. ๒๕๖๙แยกหมวด ๑๐ เป็น ๑๐.๑ วิ่งส่วนตัว / ๑๐.๒ งานวิ่ง พร้อมอัตราและเพดานที่เสนอ; เพิ่มกติกาเพซขั้นต่ำ เพดานรายปี ชั้นปีที่ ๔ และการคุ้มครองข้อมูลบน GitHub
๒.๒๑๔ พ.ย. ๒๕๖๙ปรับคู่มือและข้อกำหนดเป็นฉบับปีการศึกษา ๒๕๖๙ (แทนข้อกำหนดฯ ๒๕๖๕); เพิ่มการแจ้งเตือน นพอ. ทาง LINE และอีเมล, การแก้ไขข้อมูลส่วนตัวบนเซิร์ฟเวอร์, การแก้ข้อมูลหลักของนักเรียนโดยอาจารย์ต้องใช้รหัสผู้ตรวจ และเหตุขัดข้องการเข้าสู่ระบบผ่าน LINE

๑. วัตถุประสงค์

๑.๑ กำหนดวิธีปฏิบัติที่เป็นมาตรฐานเดียวกันในการบันทึก ตรวจสอบ รับรอง และประเมินผลกิจกรรมความดีจิตอาสาของ นพอ. ให้โปร่งใสและตรวจสอบย้อนหลังได้ทุกรายการ

๑.๒ ส่งเสริมให้ นพอ. ทุกนายบำเพ็ญประโยชน์ไม่น้อยกว่า ๕๐ ชั่วโมงต่อปีการศึกษา โดยมีชั่วโมงพื้นฐาน ๒๕ ชั่วโมงต่อภาคการศึกษา

๑.๓ ส่งเสริมสมรรถภาพร่างกายของ นพอ. ผ่านกิจกรรมวิ่งเพื่อสุขภาพ (หมวด ๑๐) และการทดสอบสมรรถภาพประจำภาค โดยทุกรายการต้องผ่านการอนุมัติของผู้ตรวจก่อนนับผล

๑.๔ กำหนดการจัดเก็บข้อมูลรายบุคคลให้ถูกต้อง ครบถ้วน และสอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. ๒๕๖๒

๒. ขอบเขต

ใช้กับ นพอ. ชั้นปีที่ ๑–๔ (ปีการศึกษา ๒๕๖๙: รุ่น ๖๙ / ๖๘ / ๖๗ / ๖๖), อาจารย์ผู้ควบคุมและอาจารย์ประจำชั้นปี, ผู้รับรองกิจกรรม (อาจารย์ ผู้ปกครอง หน่วยงานภายนอก), ผู้ตรวจการวิ่งและสมรรถภาพ และผู้ดูแลระบบสารสนเทศ

๓. คำนิยาม

คำความหมาย
รายการความดีการบันทึกกิจกรรม ๑ ครั้งของ นพอ. ในหมวด ๑–๙
รายการวิ่งการบันทึกการวิ่ง ๑ ครั้งในหมวด ๑๐ พร้อมหลักฐาน
สถานะรอตรวจรายการที่ส่งแล้วแต่ยังไม่ได้รับอนุมัติ ไม่นับชั่วโมงและไม่นับค่าพลัง
ผู้ตรวจอาจารย์หรือเจ้าหน้าที่ที่ได้รับมอบหมายและได้รับรหัสผู้ตรวจจากผู้ดูแลระบบ
ค่าพลังคะแนนพัฒนาตนเองรายคน (เต็ม ๑,๐๐๐) ใช้เพื่อสร้างแรงจูงใจ ไม่ใช่ผลการประเมินทางวิชาการ
แต้มบุญ / ออร่าชั่วโมงความดีหมวด ๑–๙ รวมกับชั่วโมงวิ่งที่อนุมัติแล้ว ใช้กำหนดระดับออร่าของตัวละคร

กระบวนการนพอ.ผู้รับรองอาจารย์ประจำชั้น / ผู้ตรวจผู้ดูแลระบบ

๒. บันทึกรายการความดีหรือรายการวิ่งในระบบRIIC

๖. ขั้นตอนการปฏิบัติงาน

SOP-GD-01 การเข้าสู่ระบบและข้อมูลประจำตัว

๑. เข้าใช้งานผ่านเมนูใน LINE Official Account ของวิทยาลัย (แนะนำ) หรือผ่านเว็บเบราว์เซอร์

๒. กรอกรหัสนักเรียน ๗ หลัก รหัสผ่านเริ่มต้นคือรหัสนักเรียน

๓. เปลี่ยนรหัสผ่านทันทีเมื่อเข้าใช้งานครั้งแรก ที่เมนู "โปรไฟล์" และตรวจสอบชื่อ-สกุล ชั้นปี ให้ถูกต้อง

๔. ห้ามให้ผู้อื่นใช้บัญชีแทน และห้ามบันทึกรายการแทนผู้อื่น

๕. ข้อมูลส่วนตัว: แก้ชื่อเล่น วันเกิด จังหวัด กรุ๊ปเลือด งานอดิเรก แนะนำตัว อีเมล และ Telegram ได้เองที่เมนู "โปรไฟล์" ข้อมูลเก็บบนเซิร์ฟเวอร์ (ชีต Profiles_2569) ใช้ได้ทุกอุปกรณ์ · ทุกครั้งที่แก้ ระบบแจ้งเจ้าของทาง LINE/อีเมล และถ้าเปลี่ยนอีเมลจะแจ้งไปอีเมลเดิมด้วย · ยศ ชื่อ-สกุล และชั้นปี แก้ได้เฉพาะอาจารย์ (ต้องใช้รหัสผู้ตรวจ)

๖. อีเมลรับแจ้งเตือน: กรอกอีเมลที่ใช้งานจริงในหน้าโปรไฟล์ เพื่อรับแจ้งผลแทนอีเมลตอบกลับของแบบฟอร์มเดิม

SOP-GD-03 การขอรับรองและลงลายมือชื่อดิจิทัล

๑. เมื่อส่งรายการ ระบบสร้างลิงก์รับรองเฉพาะรายการ ให้ นพอ. ส่งลิงก์ให้ผู้รับรองทาง LINE หรือช่องทางอื่น

๒. ผู้รับรองเปิดลิงก์ ตรวจภาพ รายละเอียด วันที่ และชั่วโมง เลือกสถานะของตน (อาจารย์ / ผู้ปกครอง / หน่วยงานภายนอก / อื่น ๆ) พิมพ์ชื่อ-ตำแหน่ง และลงลายมือชื่อบนหน้าจอ

๓. ระบบบันทึกลายมือชื่อพร้อมเวลา และส่งรายการเข้าหน้าตรวจของอาจารย์

SOP-GD-04 การตรวจและอนุมัติรายการความดี (อาจารย์)

๑. ตรวจภาพหลักฐาน ความถูกต้องของหมวด และลายมือชื่อผู้รับรอง

๒. อนุมัติรายบุคคล หรืออนุมัติทั้งกลุ่มสำหรับกิจกรรมที่มีคำสั่ง วพอ.

๓. การไม่อนุมัติต้องระบุเหตุผลทุกครั้ง เพื่อให้ นพอ. แก้ไขและส่งใหม่

๔. ระยะเวลามาตรฐาน: ตรวจให้แล้วเสร็จภายใน ๗ วันทำการ นับจากวันที่ส่ง

๕. การแจ้งผลอัตโนมัติ: ระบบแจ้ง นพอ. ทาง LINE (เมื่อผูก LINE แล้ว) และอีเมล (เมื่อกรอกในโปรไฟล์) เมื่อ ส่งรายการสำเร็จ · อนุมัติ/ไม่อนุมัติ · ชั่วโมงสะสมครบ ๕๐ ชม. (แจ้งครั้งเดียว) — อีเมลส่งในนามบัญชีเจ้าของระบบ โควตาประมาณ ๑๐๐ ฉบับ/วัน (บัญชีทั่วไป) หากเกินโควตา LINE ยังแจ้งตามปกติ

๖. การแก้ข้อมูลหลักของนักเรียน (ยศ ชื่อ-สกุล ชั้นปี อีเมล) ที่หน้าอาจารย์ ต้องกรอกรหัสผู้ตรวจ (ชุดเดียวกับหน้าตรวจการวิ่ง) ทุกครั้งที่เปิดแท็บใหม่ · รหัสผ่านของนักเรียนไม่ถูกเก็บในชีต

SOP-GD-05 รอบปีการศึกษา การยกยอด และใบบันทึกความดี

๑. ภาคการศึกษาที่ ๑: ๑ ก.ค. – ๓๐ พ.ย. / ภาคการศึกษาที่ ๒: ๑ ธ.ค. – ๓๐ มิ.ย.

๒. ระบบใช้ ๒ มาตรวัด: ยอดประจำปี (เริ่มนับใหม่ ๑ ก.ค. เพื่อประเมินเกณฑ์ ๕๐ ชม.) และ ยอดสะสมตลอดหลักสูตร (ไม่ลบข้อมูลเดิม)

SOP-GD-06 หมวด ๑๐ วิ่งเพื่อสุขภาพ

ก. การบันทึก (นพอ.) — เมนู "วิ่งเพื่อสุขภาพ & ค่าพลัง" เลือกได้ ๒ วิธี

วิธีขั้นตอนข้อควรระวัง
ภาพจากแอปวิ่งถ่ายภาพหน้าจอสรุปผล (Strava, Garmin, Nike Run Club หรือนาฬิกา) ที่เห็นวันที่ ระยะทาง และเวลาชัดเจน แล้วกรอกระยะทางและเวลาให้ตรงกับภาพตัวเลขที่กรอกต้องตรงกับภาพ มิฉะนั้นผู้ตรวจจะไม่อนุมัติ
จับ GPS ในระบบกด "เริ่มวิ่ง" อนุญาตตำแหน่ง เปิดหน้าจอค้างไว้ระหว่างวิ่ง กด "พัก" เมื่อหยุด และ "จบการวิ่ง" เมื่อเสร็จ ระบบสร้างภาพเส้นทางเป็นหลักฐานให้อัตโนมัติหากปิดหน้าจอหรือสลับแอป LINE อาจหยุดรับตำแหน่ง ทำให้ระยะขาดหาย

ข. การตรวจสอบอัตโนมัติก่อนรับรายการ

  • ระยะทาง ๐.๕ – ๔๒.๒ กม. ต่อครั้ง
  • เพซต้องอยู่ระหว่าง ๓ – ๒๐ นาที/กม. (เร็วกว่านี้ถือว่าผิดปกติ เช่น ปั่นจักรยานหรือนั่งรถ)
  • ห้ามเป็นวันในอนาคต และส่งย้อนหลังได้ไม่เกิน ๗ วัน
  • ต้องมีภาพหลักฐานทุกครั้ง และห้ามส่งซ้ำ (วันเดียวกัน ระยะเท่ากัน)
  • ในโหมด GPS ระบบตัดช่วงที่เร็วเกิน ๒๕ กม./ชม. และจุดที่สัญญาณคลาดเคลื่อนเกิน ๓๕ เมตร

ค. การคิดชั่วโมง (ข้อเสนอ — รอผู้มีอำนาจอนุมัติ)

หลักคิด: ข้อกำหนดฯ ปีการศึกษา ๒๕๖๕ และ ๒๕๖๙ (ภาคผนวก ก) ไม่มีหมวดการวิ่งที่อนุมัติแล้ว และกิจกรรมที่ทำเองโดยไม่มีคำสั่ง (หมวด ๗ ความดีทั่วไป) ได้โควตาน้อยที่สุด การวิ่งส่วนตัวเป็นประโยชน์ต่อตนเองมากกว่าส่วนรวม จึงกำหนดให้ ได้ชั่วโมงใกล้เคียงหมวด ๗ และรวมทั้งปีไม่เกินร้อยละ ๑๒ ของเกณฑ์ ๕๐ ชม./ปี (๖ ชม.) เพื่อไม่ให้แทนที่งานจิตอาสาจริง ส่วนแรงจูงใจหลักของการวิ่งอยู่ที่ค่าพลังและเลเวลตัวละคร

ประเภทการคิดชั่วโมงเพดานหลักฐาน
๑๐.๑ วิ่งส่วนตัวทุก ๑๐ กม. = ๑ ชม. ปัดลงทีละ ๐.๕ ชม. (๕ กม. = ๐.๕, ๑๐ กม. = ๑ ชม.)๑ ชม./วัน · ๓ ชม./ภาค · ๖ ชม./ปี (ชั้นปีที่ ๔: ๔ ชม./ปี)ภาพหน้าจอแอปวิ่ง หรือภาพเส้นทาง GPS จากระบบ
๑๐.๒ งานวิ่ง / วิ่งการกุศลที่มีผู้จัด๒ ชม./งาน (ระยะตั้งแต่ ๕ กม.)๒ งาน/ภาค (๔ ชม./ภาค) แยกจากเพดาน ๑๐.๑ภาพเบอร์วิ่ง ใบประกาศ หรือภาพที่เส้นชัย พร้อมระบุชื่องาน

เหตุผลของตัวเลข: ระยะ ๑๐ กม. ใช้เวลาวิ่งจริงประมาณ ๖๐–๗๐ นาทีสำหรับ นพอ. ทั่วไป (เพซ ๖–๗ นาที/กม.) จึงเทียบได้กับเวลาที่ใช้จริง ๑ ชม.; เพดานวันละ ๑ ชม. กันการสะสมด้วยการวิ่งระยะไกลครั้งเดียว; งานวิ่งที่มีผู้จัดมีส่วนร่วมกับสังคม (ค่าสมัครเข้าการกุศล) จึงได้มากกว่าการวิ่งส่วนตัว

เงื่อนไขเพิ่มเติม

  • ได้ชั่วโมงเฉพาะเมื่อเพซไม่ช้ากว่า ๑๐ นาที/กม. (ช้ากว่านี้ถือเป็นการเดิน บันทึกค่าพลังได้แต่ไม่ได้ชั่วโมง)
  • ระยะต่ำกว่า ๕ กม. บันทึกค่าพลังได้ แต่ยังไม่ได้ชั่วโมง
  • งานวิ่งที่ไปตาม คำสั่ง วพอ. ให้บันทึกในหมวด ๒ (โครงการภายนอก) แทน ห้ามบันทึกซ้ำทั้งสองหมวด
  • ชั่วโมงคำนวณและตัดเพดาน ณ วันที่ผู้ตรวจอนุมัติ จากรายการที่อนุมัติแล้วเท่านั้น ระหว่างรอตรวจระบบแสดงเพียง "ชั่วโมงโดยประมาณ"
  • วันที่วิ่งต้องอยู่ในช่วงภาคเรียนที่กำหนด มิฉะนั้นได้ ๐ ชม.
  • หน้า "วิ่งเพื่อสุขภาพ" แสดงชั่วโมงที่ใช้ไปเทียบเพดานของภาคและของปี ให้ นพอ. ตรวจสอบได้เอง
  • ผู้ดูแลระบบปรับค่าทุกข้อได้ที่หน้าผู้ตรวจ แท็บ "ตั้งค่ากติกา" มีผลกับการอนุมัติครั้งถัดไป รายการที่อนุมัติแล้วไม่ถูกคำนวณใหม่

ง. การตรวจและอนุมัติ (ผู้ตรวจ) — แถบเมนู "ตรวจการวิ่ง & สมรรถภาพ"
๑. กรอกรหัสผู้ตรวจ (ระบบจำไว้เฉพาะแท็บที่เปิดอยู่)

๒. เปิดภาพหลักฐาน เทียบวันที่ ระยะทาง และเวลากับที่ นพอ. กรอก

๓. ตรวจประเภท: หากเป็น ๑๐.๒ ต้องเห็นชื่องานและเบอร์วิ่ง/ใบประกาศ หากเป็นงานตามคำสั่ง วพอ. ให้ไม่อนุมัติพร้อมแนะนำให้บันทึกหมวด ๒

๔. กด "อนุมัติ" (ระบบแจ้งจำนวนชั่วโมงที่ได้จริงหลังตัดเพดาน) หรือ "ไม่อนุมัติ" พร้อมเหตุผล

๕. รายการที่ตรวจแล้วเปลี่ยนสถานะซ้ำไม่ได้ หากตรวจผิดให้แจ้งผู้ดูแลระบบแก้ไขในชีตพร้อมบันทึกเหตุผล

๖. ระยะเวลามาตรฐาน: ตรวจภายใน ๓ วันทำการ

SOP-GD-07 การทดสอบสมรรถภาพและค่าพลังรายคน

๑. จัดทดสอบอย่างน้อยภาคการศึกษาละ ๑ ครั้ง ได้แก่ วิ่ง ๒.๔ กม. (นาที:วินาที), ดันพื้น ๒ นาที และลุกนั่ง ๒ นาที

๒. ผู้ตรวจบันทึกผลในแท็บ "สมรรถภาพ" ภายใน ๓ วันทำการหลังการทดสอบ ระบบบันทึกชื่อผู้บันทึกและเวลาโดยอัตโนมัติ

๓. องค์ประกอบค่าพลัง (เต็ม ๑,๐๐๐) — นับเฉพาะรายการที่อนุมัติแล้ว

ด้านคะแนนเต็มเกณฑ์เต็ม
ความอึด๒๕๐ระยะสะสม ๒๐๐ กม.
ความเร็ว๑๕๐เพซเฉลี่ย ๔:๐๐ นาที/กม. (เริ่มนับเมื่อวิ่งที่อนุมัติแล้วครบ ๓ ครั้ง)
ความสม่ำเสมอ๑๐๐มีการวิ่งครบ ๘ ใน ๘ สัปดาห์ล่าสุด
สมรรถภาพร่างกาย๒๐๐๒.๔ กม. ≤ ๑๐ นาที, ดันพื้น ≥ ๖๐, ลุกนั่ง ≥ ๖๐ (ผลทดสอบล่าสุด)
แต้มบุญ๓๐๐ชั่วโมงความดี + ชั่วโมงวิ่ง ≥ ๕๐ ชม.

๔. ระดับออร่าตามแต้มบุญ: ไม่มี (< ๑๐ ชม.) → จาง (๑๐) → เงิน (๒๐) → ทอง (๓๕) → ศักดิ์สิทธิ์ (๕๐ ชม. ขึ้นไป)

๕. ค่าพลัง เลเวล และออร่า เป็นเครื่องมือสร้างแรงจูงใจ ไม่ใช้แทนผลการประเมินทางวิชาการหรือการตัดสินทางวินัย

๓. วิธีบันทึก (เปลี่ยนจากแบบฟอร์มเดิมเป็นระบบบันทึกความดี)

1. เปิด LINE Official Account ของวิทยาลัย แล้วกดเมนู "บันทึกความดี" (หรือเปิดเว็บ rtafnc-gooddeeds.pages.dev)
2. ระบบเข้าสู่ระบบอัตโนมัติด้วย LINE ที่ผูกกับรหัส นพอ. แล้ว · ครั้งแรกให้เข้าด้วยรหัส นพอ. ๗ หลัก และเปลี่ยนรหัสผ่านทันที
3. เมนู "✍️ บันทึกความดี" → เลือกหมวด → กรอกวันที่ ชั่วโมง รายละเอียด → แนบรูป → ส่ง (ระบบแสดงโควตาคงเหลือและเตือนเมื่อเกินเพดาน)
4. ส่งลิงก์ขอรับรองให้ผู้รับรอง (อาจารย์ / ผู้ปกครอง / หน่วยงานภายนอก / อื่น ๆ) ลงลายมือชื่อบนหน้าจอ
5. รออาจารย์ตรวจ (มาตรฐาน ๗ วันทำการ)

๔. การแจ้งผล (แทนอีเมลตอบกลับของแบบฟอร์มเดิม)

ระบบแจ้งทาง LINE (เมื่อผูก LINE แล้ว) และ อีเมล (เมื่อกรอกอีเมลในหน้าโปรไฟล์) เมื่อ

  • ส่งรายการความดี/ผลวิ่งสำเร็จ (ได้รับแล้ว รอตรวจ)
  • อาจารย์อนุมัติ หรือไม่อนุมัติ (พร้อมเหตุผล)
  • ข้อมูลส่วนตัวถูกแก้ไข (ถ้าไม่ได้แก้เอง ให้แจ้งอาจารย์ทันที)
  • ชั่วโมงสะสมครบ ๕๐ ชม.

๕. การตรวจสอบชั่วโมง

  • หน้า "หน้าหลัก" แสดงชั่วโมงสะสมปีการศึกษา ๒๕๖๙ เทียบเกณฑ์ ๕๐ ชม. แยกรายหมวด
  • หน้า "ประวัติความดี" แสดงทุกรายการพร้อมสถานะ (รอตรวจ / อนุมัติ / ไม่อนุมัติ) และพิมพ์ใบบันทึกความดี A4 ได้
  • ข้อสงสัยติดต่อแอดมินชั้นปี หรือพิมพ์ข้อความใน LINE Official Account
