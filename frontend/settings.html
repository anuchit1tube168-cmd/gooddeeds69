⚙️ ตั้งค่าระบบ

💬 การแจ้งเตือน Telegram

📌 วิธีตั้งค่า Telegram Bot:

  1. เปิด Telegram → ค้นหา @BotFather
  2. พิมพ์ /newbot และตั้งชื่อ Bot
  3. BotFather จะส่ง Token ให้
  4. ให้อาจารย์ start Bot แล้วใช้ @userinfobot หา Chat ID
  5. กรอก Token และ Admin Chat ID ด้านล่าง
Token จาก @BotFather ห้ามเผยแพร่
Chat ID ของอาจารย์ที่รับแจ้งเตือน
💚 การแจ้งเตือน LINE Notify

📌 วิธีตั้งค่า LINE Notify:

  1. ไปที่ notify-bot.line.me
  2. Login ด้วยบัญชี LINE แล้วกด "Generate Token"
  3. เลือกกลุ่ม LINE ที่ต้องการรับแจ้งเตือน หรือเลือก "1-on-1 chat"
  4. Copy Token มาวางด้านล่าง
Token จาก LINE Notify (ใช้แจ้งเตือนเข้ากลุ่ม LINE)
